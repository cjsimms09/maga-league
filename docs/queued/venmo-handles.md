# VENMO HANDLES — payment info, site-wide (data-spine manual-entry surface)

Queue position (Cory): **behind the draft-critical items** — nice-to-have now, **load-bearing on settlement day.** Joins the data-spine's legitimate manual-entry list (a new fact, exists nowhere else — entered once, rendered everywhere, never re-typed).

1. **ENTRY:** a `venmo` handle field on each owner's profile — entered once by each owner, validated loosely (strip a leading `@`, store the bare handle), editable anytime.
2. **THE NAG:** a dismissible-but-recurring home-page banner for any logged-in owner whose handle is missing — "Add your Venmo so people can pay you 💸" with one-tap inline entry, re-appearing each session until filled. Plus a **commissioner view** (Cory) listing who's still missing theirs, to hound stragglers in the group chat.
3. **DISPLAY EVERYWHERE MONEY CHANGES HANDS:** the payout/settlement screen renders each owner's handle beside their line as a tappable deep link (`venmo.com/u/<handle>`) — the settlement becomes an actionable invoice: "You owe Michael $X → @his-handle, tap to pay." The side-bet ledger gets the same on BOTH parties of every bet; the Finances dues section shows Cory's handle so buy-ins flow to the right place. Missing handles render **"no Venmo on file" — loud, never blank.**
4. **THE ANNUAL inherits it:** January's who-owes-whom settlement report arrives with payment links baked in automatically.
5. **Robot:** profile save round-trips; the nag fires for missing / suppresses for filled; the settlement renders links; a no-handle owner renders the loud fallback.
