  tip marker → the gate BUILDS it. **The fresh board should be live now.**

**What Cory does NOT have on the live site** is therefore not "everything since the
freeze" — it is precisely **what main itself lacks: the relay branch** (see B).

**The remaining hole is verification, and it points at draft morning.**
`86e42bc2` was pushed by draft-bot with `GITHUB_TOKEN`, and GitHub does not trigger
workflows on such pushes — **there is no deploy-verify run for it**, and there
never is one for any nightly board push. Netlify's webhook is external and fires

day. On 08-22 the morning board rebuild will deploy unverified, with the next
automated check scheduled after the draft. Mitigation that exists today: the war
room header prints "Board built <date> · N players" — one glance at the LIVE site
against that morning's rebuild log closes the gap by hand.
